# Contributing

Thanks for taking an interest in this project — it's a hobby build, so contributions are welcome but there's no formal process. A few guidelines:

## Reporting issues

- Bugs, crashes, or confusing setup steps: open an issue with what you did, what you expected, and what happened instead.
- Hardware variants: if you got this working with a different microcontroller (ESP32, Teensy, etc.) or different sensor models than the ones in the README, please open an issue or PR describing the substitution — voltage ranges and wiring can differ enough to matter, and this helps keep the docs accurate for others.

## Pull requests

- Keep PRs focused — one change/feature per PR is easier to review than a bundle of unrelated tweaks.
- For firmware changes: note the board you tested on.
- For Mac app changes: a screenshot or short clip of the change in action is appreciated for anything UI-related.
- No strict style guide is enforced yet; just try to match the formatting already in the file you're editing.

## Scope

This project is meant to stay recreational/educational — see the disclaimer in the README. Contributions that push it toward being marketed or used as an actual lie-detection/forensic tool are out of scope.

## Questions

Open an issue — happy to talk through ideas before you put work into a PR.
